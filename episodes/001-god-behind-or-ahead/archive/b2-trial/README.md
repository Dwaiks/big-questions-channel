# Archived: B2 illustrated trial (23 Nov 2026)

First visual trial of episode 1: Flow still images (cut-outs on green, layered over backgrounds) animated with the directing-stickman-videos B2 renderer.

- 40-second preview of scenes 1–2: `preview/episode-001-preview.mp4`
- Renderer project: `preview/project.json` (built by `preview/build_project.py`)
- Flow prompts, uploads, cut-outs, test frames: `art/`

Outcome: technically working (narration, phrase captions, music, ambience), but the visuals were judged too flat compared with richly illustrated channels: pasted-on cut-outs, minimal faces, too few images. Next approach: silent Flow video clips per shot, assembled to the narration.

Git tag: `ep1-b2-trial`.
