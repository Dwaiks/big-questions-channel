# Channel templates

Templates fix the process, never the content. Every video keeps its own argument, the author's view and its own visuals.

## 1. Research brief

The author reads it first (about 20 minutes).

```markdown
# <Question>
- The question in one line, and why people care
- 5-sentence plain explanation (the author should be able to retell it)
- Key facts with sources (5–8 links)
- Common misconceptions (2–3)
- Where the argument is uncertain or debated
- What popular existing videos cover, and what they skip (our gap)
- Open questions for the author's "My view" paragraph
```

## 2. Script

1,200–1,700 words, 8–12 minutes.

```markdown
1. Opening (0:00–0:30): a concrete scene or question; no conclusion given away
2. The everyday assumption (about 1 min)
3. Step-by-step reasoning, 3–5 steps, each with one picture-able example,
   viewed through "measured against what?"
4. The turn: where the logic leads that people don't expect
5. My view (80–150 words, the author's own words)
6. The open question to viewers + one-line teaser of the next video
```

Script format: numbered scenes. For each scene: the narration, then a one-line visual note in brackets.

## 3. Shorts

2–3 per video.

```markdown
- One idea per Short, 30–55 s, vertical 9:16
- Starts on the most surprising line, ends on the question
- Re-laid-out for portrait (not a crop), own captions
- Pinned comment links to the full video
```

## 4. Publishing pack

```markdown
- 3 title options (curiosity + clarity, under 60 characters)
- 2 thumbnail concepts for YouTube's Test & Compare (one character, one object)
- Description: 2-line hook, chapters, sources, affiliate links, disclosure line
- Tags + 5 keywords
- Pinned comment with the question to viewers
```

## 5. 7-day review

The author does this 7 days after upload (15 minutes).

```markdown
- Click-through rate (below ~4% → title/thumbnail need work)
- Average % viewed and the first-30-seconds drop
- Retention dips and spikes: the script line at each
- Top comments: new ideas, confusions
- One lesson for the next script (logged in the tracker's Results sheet)
```
